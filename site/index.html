Write the opponent, then play it先写对手，再和它打

Edit the prompt. Preview every street.编辑提示词，逐街预览。

Each opponent gets its own model, play style and prompt. Search for equity, position or pot odds and insert them as live values. Preview builds the exact request for preflop, flop, turn and river locally — no model call, no cost. 每个对手都有自己的模型、风格和提示词。搜索胜率、位置、底池赔率等信息并插入为实时变量。预览会在本地为翻前、翻牌、转牌、河牌生成完整请求——不调用模型，不产生费用。

Pick your table.挑选你的牌桌。

Play against JEV, Gemini, Claude, GPT, Grok, DeepSeek and Kimi through OpenRouter. Add or remove seats, swap models per opponent, and your bankroll and settings are saved in your browser. 通过 OpenRouter 对战 JEV、Gemini、Claude、GPT、Grok、DeepSeek 和 Kimi。增减座位、为每个对手切换模型，资金和设置都保存在你的浏览器里。

Made for phones, too.手机上同样好用。

Two ways to play两种玩法

  1. Online在线

    Open frankie-poker.vercel.app. Local Practice works right away, no key. For model opponents, tap your avatar, open AI connection and paste your own OpenRouter key. It stays in your browser; requests go straight to the provider. 打开 frankie-poker.vercel.app，本地练习无需 key 即可开玩。想和模型对战，点击你的头像，在 AI 连接 中填入你自己的 OpenRouter key。key 只保存在你的浏览器里，请求直接发往模型服务商。

    Open the app打开应用

  2. Locally本地

    Node.js 22+ and npm. Put your key in .env.local — only the local dev server reads it. 需要 Node.js 22+ 和 npm。把 key 写进 .env.local——只有本地开发服务器会读取它。 

git clone https://github.com/SonghaiFan/frankie-poker.git
cd frankie-poker
npm ci
cp .env.example .env.local   # set OPENROUTER_API_KEY
npm run dev

Use a key with a spending limit. Chips are virtual; model calls use your own API balance. 建议使用设置了消费上限的 key。筹码是虚拟的，模型调用消耗你自己的 API 余额。
