# Launch copy

## English

**What happens when you give a poker opponent a prompt?**

Frankie Hold'em is an open-source Texas Hold'em playground where you can play against language models, edit each opponent's strategy, and inspect what the model sees before taking it to the table.

Bring your own OpenRouter key, run it locally, and tune opponents through a minimal UI. Your coding agent can help set up the project, draft strategies, or add new poker-information plugins. Built-in street-by-street previews help you check the input; actual hands let you observe the behavior.

Shout-out to Offsuit for the modern, minimal poker design that inspired the UI/UX.

Code, screenshots, and setup guide: https://github.com/SonghaiFan/frankie-poker

Virtual chips; model calls use your own API balance. MIT-licensed source. Strategy experiments, not claims of GTO correctness.

## 中文

**给德扑对手写一段提示词，它会怎么打？**

Frankie Hold'em 是一个开源德州扑克实验场。你可以和大模型打牌，为每个对手选择模型、调整打法、编辑策略，并预览它在不同轮次能看到的信息。

带上自己的 OpenRouter key，本地启动即可。也可以把项目交给你的 AI agent，让它帮你完成配置、写策略，或增加新的扑克分析变量，再回到 UI 里预览和试验。

特别致谢 Offsuit：它现代、极简的扑克 UI/UX 启发了这个项目的设计。

代码、截图和上手指南：https://github.com/SonghaiFan/frankie-poker

虚拟筹码；模型请求消耗自己的 API 余额。源码采用 MIT。欢迎一起尝试、调整、贡献，不把少量牌局胜负当成策略优劣的结论。
